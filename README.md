# pair-wise-yf-52 戏剧排练台词版本与舞台提示管控

## 源提示词摘要
导演、编剧、舞台监督和演员共同维护不同版本的剧本、角色台词、上下场提示、道具与灯光音效提示。编剧提交后需逐条合并，演员可查看最新版并标记疑问；支持版本对比、单条采纳、批注、冲突处理、排练模式、大字号提词和断网缓存。

## 技术栈
Angular + TypeScript + Angular Material + NgRx + Angular Router + RxJS + Angular CDK + Transloco。

## 已实现闭环
- **三方合并编剧新稿（排练稿 ← 编剧稿，以共同祖先 base 对齐）**
  - 编剧没动过的行：原样保留舞台监督的采纳/退回/待确认结论。
  - 只有编剧动过：并入新文本并回到「待确认」交舞台监督复审。
  - 两边都动过：不盖掉退回/采纳决定，挂成「待裁决」，保留双方文本与原结论；可「保留排演稿」或「采用编剧稿」裁决，采用时旧结论仍在 `priorDecision` 留痕。
  - 编剧删除有结论的行：挂「删除待裁决」；无结论行随稿移除，行上疑问转入版本孤儿疑问，记录不丢。
- **待裁决按版本隔离**：争议存放在各自版本上，合并途中切到别的版本不会串扰，回来可继续裁决。
- **离线演员疑问**：离线时进入发件箱并各自记录修订顺序（seq）与当时文本/版本修订号；恢复网络（或手动模拟）后按 seq 重放，晚到疑问按最新排练版本重新比对（文本/修订号变化即标「需重新比对」），旧结论不会盖回新稿；版本尚未到达的条目留在发件箱重试。
- **稳定行标记（stableId）+ 历史存档迁移**：旧存档没有行标记也可打开；启动/导入时由确定性哈希补建 stableId（重复行保证唯一），旧采纳/退回结论迁为留痕，迁移后照常版本对比、进入大字号提词；迁移幂等。
- 版本创建/切换、逐条采纳/退回、行内改稿与删除、拖拽排序。
- 按 stableId 对齐的版本对比（新增/改动/删除/未变 + 待裁决计数）。
- 排练提词模式：大字号仅展示已采纳且无争议的台词与提示。
- localStorage 持久化与在线/离线切换。

## 核心模块
- `src/app/state/script.model.ts` — 领域模型、schema 版本与 stableId 哈希。
- `src/app/state/script.migration.ts` — 旧存档（无 stableId）迁移。
- `src/app/state/script.merge.ts` — 三方合并与待裁决处理纯函数。
- `src/app/state/script.sync.ts` — 离线发件箱按 seq 重放与新鲜度比对。
- `src/app/state/script.diff.ts` — 基于 stableId 的版本对比。
- `src/app/state/script.reducer.ts` / `script.actions.ts` — NgRx 状态与动作（含示例数据）。

### 手动演示路径
1. 打开后在「并入编剧新稿」选 v13 → 并入 v12：l1/l2 因与舞台监督结论冲突挂待裁决，l2 的退回不被覆盖；l3 类无结论行自动更新。
2. 对争议分别选「保留排演稿 / 采用编剧稿」；切版本可见待裁决徽标只留在 v12。
3. 点「离线缓存中」断网 → 给台词记若干疑问（发件箱计数增加）→ 可再改一次行文本 → 「模拟恢复网络并重放」：旧疑问标记「晚到 · 需按最新稿重新比对」。
4. 右侧「历史存档」→「导入旧版存档（演示）」：无 stableId 的旧稿自动升级，可对比、可进提词，旧疑问仍在。
